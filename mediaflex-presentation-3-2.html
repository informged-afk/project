01 · Введение

Обзор проекта

Современный фронтенд в сочетании с гибким бэкендом на Python Flask — полноценный учебный аналог стриминг-сервиса, разработанный «с нуля» и охватывающий полный цикл: от регистрации пользователя до администрирования каталога контента.

Идея и мотивация

  • Показать на практике полный full-stack цикл: клиент → REST API → база данных.
  • Воспроизвести ключевые механики Netflix-подобных сервисов: каталог, плеер, роли доступа.
  • Сделать проект без тяжёлых фреймворков — на «чистых» технологиях, чтобы продемонстрировать понимание основ.

Кому предназначен

  • Пользователь — регистрируется, входит в систему и смотрит фильмы из каталога.
  • Администратор — управляет контентом и учётными записями через отдельную панель.
  • Проект демонстрирует связку клиент-сервер без сторонних CMS и конструкторов.
02 · Планирование

Цели и технический стек

Основные цели

  • Полноценная медиаплатформа с каталогом и плеером
  • Разделение ролей: пользователь и администратор
  • Загрузка видео и постеров через панель управления
  • Удобная база данных пользователей и медиаконтента
  • Поддержка как локальных файлов, так и внешних ссылок (YouTube/Rutube)

Технологический стек

  • Frontend: HTML5, CSS3 (без тяжёлых фреймворков)
  • Backend: Python 3 + Flask REST API
  • Database: SQLite3 с двумя таблицами (users, movies)
  • Security: Flask-Bcrypt для безопасного хеширования паролей
  • Прочее: Flask-CORS, Werkzeug (secure_filename, ProxyFix)
03 · Продукт

Архитектура и интерфейс

Каталог

Красивое представление фильмов с постерами, годами выпуска, жанрами и рейтингом в тёмном стиле. Стартовый набор — «Интерстеллар», «Начало», «Тёмный рыцарь», «Дюна: Часть вторая» — дополняется контентом из БД.

Плеер

Интеграция с локальными видеофайлами, а также видеохостингами YouTube и Rutube через embed/iframe — для бесшовного просмотра без привязки к формату источника.

Безопасность

Защищённые сессии, хеширование паролей через Bcrypt и двухуровневая проверка прав доступа на стороне бэкенда для каждого административного запроса.

04 · Доступ

Роли пользователей

Пользователь

  • Просмотр полного каталога фильмов и сериалов
  • Регистрация и безопасный вход в систему
  • Просмотр видеоматериалов с подробными описаниями
  • Возможность выхода из аккаунта

Администратор

  • Все возможности обычного пользователя
  • Доступ к эксклюзивной панели управления сайтом
  • Управление пользователями (повышение, удаление)
  • Добавление, редактирование и удаление фильмов из БД
  • Первый зарегистрированный пользователь автоматически становится администратором
05 · Управление

Админ-панель (Центр управления)

  • Пользователи: полный список зарегистрированных аккаунтов с возможностью редактирования, выдачи админ-прав и удаления.
  • Фильмы: интерактивный список записей в базе данных с быстрой правкой метаданных и удалением устаревшего контента.
  • Добавление контента: удобная форма для загрузки постеров, видеофайлов или указания внешних ссылок (YouTube/Rutube).

Формы и модальные окна

Добавление и редактирование выполняются через модальные окна без перезагрузки страницы.

Валидация на бэкенде

Название, год и жанр — обязательные поля; сервер отклоняет некорректные форматы файлов до записи в БД.

Защита последнего админа

Систему нельзя оставить без администратора — удаление единственного admin-аккаунта блокируется бэкендом.

06 · Данные

База данных (SQLite3)

Таблица: users

  • id: INTEGER (Primary Key, autoincrement)
  • username: TEXT
  • email: TEXT (уникальный)
  • password: TEXT (Bcrypt-хэш)
  • role: TEXT (user / admin)
  • created_at: TIMESTAMP (по умолчанию — время создания)

Таблица: movies

  • id: INTEGER (Primary Key)
  • title / year / genre: основная информация
  • rating: REAL (от 0 до 10)
  • description: TEXT
  • video_url / poster_url: внешние ссылки
  • video_file / poster_file: пути к загруженным файлам

Схема БД создаётся автоматически при первом запуске (init_db()), а встроенная функция миграции добавляет недостающие колонки в уже существующую базу — это позволяет безопасно обновлять структуру без потери данных.

07 · Качество

Безопасность и UX

Безопасность

Хеширование паролей, защищённые локальные сессии и строгая проверка прав на бэкенде. Минимальная длина пароля — 6 символов, email проверяется на уникальность.

Адаптивность

Полная поддержка мобильных устройств, планшетов и десктопов благодаря CSS Grid и Flexbox — интерфейс перестраивается под ширину экрана.

Интерфейс

Гладкие hover-эффекты на карточках, toast-уведомления об ошибках и успехе действий, предварительный просмотр постеров перед загрузкой.

08 · Результаты

Итоги проекта

  • Аутентификация: полностью реализована регистрация, роли и безопасное хранение паролей через Bcrypt.
  • Каталог и плеер: интегрированы статические и динамические фильмы с поддержкой внешних платформ YouTube и Rutube.
  • Администрирование: развёрнута полнофункциональная панель управления контентом и пользователями.
  • Хранение файлов: настроена загрузка и раздача постеров и видео объёмом до 2 ГБ с проверкой формата.
  • База данных: реализована схема с автоматической инициализацией и миграцией структуры.
09 · Демонстрация

Готово к демонстрации

Платформа полностью настроена и готова к запуску. Сервер поднимается одной командой, база данных инициализируется автоматически при первом старте.

python server.py  →  http://localhost:5000
